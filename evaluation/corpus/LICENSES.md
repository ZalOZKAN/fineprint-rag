# Evaluation corpus: provenance and licensing

This is the corpus the golden sets, retrieval comparisons and README numbers
are all measured against, not a document store Fineprint expects you to use:
the app itself works on whatever you load into it, empty by default (see
`config.LIBRARY_DIR`). It is public-domain U.S. federal regulation, safe to
redistribute in a public repository. Works of the United States Government are
not subject to copyright in the United States (17 U.S.C. 105). Every file
below is reproduced verbatim from the Electronic Code of Federal Regulations
(eCFR), 2024-01-01 edition, and may be copied and redistributed without
restriction.

## The wider corpus

Added by `python scripts/fetch_public_corpus.py --wide`. Each file is one whole
CFR part; the citation is in the file's own banner. Titles 12 (CFPB Regulations
B, DD, E, F, M, V, X), 16 (further FTC consumer rules), 29 (FMLA and the
wage-and-hour rules, OSHA inspections) and 44 (the rest of the NFIP program).
See `WIDE_PARTS` in the fetch script for the exact list.

Regenerate these with:

    python scripts/fetch_public_corpus.py

These files are reproduced character for character, including punctuation such as
the em dash, so they remain a faithful copy of the regulation. The project's house
style rule against em dashes applies to authored prose, not to quoted source.

## Your own documents

Anything else you add to this folder is git ignored. `.gitignore` excludes
everything here except the two generator outputs above and this file, so a
personal policy or lease dropped in for real use never enters version control.
